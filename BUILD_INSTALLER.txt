BUILDING A REAL WINDOWS INSTALLER (Setup.exe)
==============================================

This packages the app + Python + the real Myriad Pro Chromium renderer into
one offline installer that anyone can run on a Windows PC with no Python,
no "pip install", nothing -- they just double-click Setup.exe.

You only need to do this ONCE on your own PC (the one that already has the
project set up and working via `python app.py`). The output is a single
NameTableGeneratorSetup.exe file you can then copy/share anywhere.


WHAT YOU NEED FIRST
--------------------
1. The project already working on your PC (you've already done this --
   venv created, `pip install -r requirements.txt`, `playwright install
   chromium`, and `python app.py` opens the app at localhost:5000).

2. Inno Setup (free, ~5MB): https://jrsoftware.org/isdl.php
   Download "innosetup-6.x.x.exe" and install it with default options.


NEW FILES ADDED TO YOUR PROJECT
--------------------------------
Copy these three files into your C:\nametag_generator folder, alongside
app.py (same folder as build_installer.bat, installer.iss below):

  - paths.py              (updated helper -- also replaces the old one
                            if you already have a file with this name)
  - build_installer.bat
  - installer.iss

Also re-copy the updated app.py, generate.py, and generate_html.py from
this same delivery -- they've been adjusted to work correctly once
packaged (this does not change how they behave when you run them the
normal way with `python app.py`).


STEP 1 - Build the app bundle
-------------------------------
Open Command Prompt in C:\nametag_generator and run:

    build_installer.bat

This will:
  - install PyInstaller into your venv
  - find Playwright's driver files and your downloaded Chromium browser
  - bundle everything (app code, templates, fonts, background image,
    Chromium browser, Playwright's driver) into dist\NameTableGenerator\

This step takes a few minutes and produces a few hundred MB of files in
dist\NameTableGenerator\. That's expected -- Chromium alone is ~300MB.

Test it before continuing: double-click
    dist\NameTableGenerator\NameTableGenerator.exe
Your browser should open to the app automatically, exactly like before.
Close it, then continue.


STEP 2 - Build the installer
------------------------------
1. Open installer.iss by double-clicking it (opens in Inno Setup).
2. Click Build -> Compile (or press Ctrl+F9).
3. When it finishes, you'll have:
       Output\NameTableGeneratorSetup.exe

That file is a normal Windows installer -- Start Menu shortcut, optional
Desktop icon, and a proper uninstaller listed in "Add or Remove Programs".
It's fully self-contained (~350-400MB), so it works offline, on any
Windows 10/11 PC, no Python required.


SHARING IT
----------
Copy NameTableGeneratorSetup.exe to a USB stick, shared drive, or upload
it somewhere -- whoever runs it gets the full app installed like any other
Windows program.


TROUBLESHOOTING
----------------
"Could not find Playwright's driver folder"
  -> Your venv's playwright package isn't installed correctly. Re-run
     `pip install -r requirements.txt` inside the activated venv.

"Could not find %LOCALAPPDATA%\ms-playwright"
  -> Run `playwright install chromium` (inside the activated venv) first.

The built .exe opens a black window but no browser
  -> Wait a couple seconds, Chromium's first launch after installing can
     be slow. If it never opens, go to
     http://localhost:5000 manually in your browser.

Windows SmartScreen warns "Windows protected your PC" when running Setup.exe
  -> Expected for installers that aren't code-signed (code signing costs
     money and isn't necessary for personal/internal use). Click
     "More info" -> "Run anyway".

Antivirus flags the installer or the bundled Chromium
  -> False positive, common with bundled browser binaries. Add an
     exception if needed.
